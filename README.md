# FixNear

FixNear es una aplicación móvil desarrollada en Android Studio con Jetpack Compose.  
Su objetivo es conectar usuarios con trabajadores, servicios y empleos cercanos.

## Funcionalidades actuales

- Pantalla de bienvenida
- Inicio de sesión visual
- Registro de usuario
- Verificación simulada
- Menú principal
- Perfil de usuario
- Búsqueda de servicios
- Mapa simulado
- Perfil de trabajador
- Empleos cercanos
- Modo trabajador
- Escaneo QR pendiente
- Navegación entre pantallas

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Jetpack Compose
- Gradle
- Git
- GitHub
- GitHub Actions

## DevSecOps aplicado

El proyecto incluye prácticas iniciales de DevSecOps:

- Repositorio con control de versiones en GitHub
- Pipeline CI/CD con GitHub Actions
- Compilación automática del proyecto
- Ejecución de pruebas unitarias
- Monitoreo básico mediante GitHub Actions
- Archivo YAML como infraestructura como código

## Pipeline CI/CD

El archivo del pipeline se encuentra en:

.github/workflows/android-ci.yml

Este workflow realiza:

- Descarga del código
- Configuración de JDK
- Permisos de Gradle
- Compilación del proyecto
- Ejecución de pruebas unitarias
