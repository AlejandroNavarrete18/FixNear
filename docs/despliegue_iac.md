# Despliegue IaC - FixNear

## Descripción

El proyecto FixNear utiliza un archivo de configuración en GitHub Actions para automatizar el proceso de compilación y pruebas del proyecto.

Este archivo se considera una práctica de Infraestructura como Código, ya que define mediante código el entorno necesario para ejecutar el pipeline.
